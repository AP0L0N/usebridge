# Contributing to Bridge

Thank you for helping. Bridge is published under the AGPL-3.0-or-later (see [LICENSE](LICENSE)).

## Contributor Licence Agreement (required)

**Every contribution (code, documentation, design or translations) requires that you agree to our
[Contributor Licence Agreement](CLA.md) first.** You keep the copyright in your work. The CLA gives
LANTIS (Tilen Poje s.p.) a licence to use your contribution and to license Bridge under other terms
in the future.

How to agree: when you open your first pull request, our CLA bot (CLA Assistant Lite, a GitHub Action)
posts a comment. You sign by replying with this exact comment:

    I have read the CLA Document and I hereby sign the CLA

The bot records your GitHub username, the date and the pull request in the `cla-signatures` branch of
this repository. The CLA version you signed is the one linked in the bot's comment. We cannot merge pull requests until the CLA is
confirmed. If you contribute on behalf of your employer, make sure your employer allows it (see CLA
section 4).

## How to contribute

1. Open an issue first for larger changes, so we can agree on the approach.
2. Fork the repository and create a branch.
3. Run `php artisan test` and `npm run build` before you open a pull request.
4. Don't include secrets, tokens, real personal data or other people's code you're not allowed to share.

## Security

Please don't open public issues for security vulnerabilities. Email **support@usebridge.si** instead.
