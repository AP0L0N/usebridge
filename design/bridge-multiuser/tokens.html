Connect your Grok bot

Bridge speaks MCP. Point a Grok connector at this server and send your token as a header.

Server URL
https://bridge.tilenpoje.eu/mcp
Auth header
Authorization: Bearer brg_live_••••

Use your own token in place of brg_live_••••.

JSON connector config
{
  "mcpServers": {
    "bridge": {
      "url": "https://bridge.tilenpoje.eu/mcp",
      "headers": { "Authorization": "Bearer brg_live_EXAMPLE_xxxxxxxxxxxxxxxxxxxxxxxx3f9a" }
    }
  }
}

Three steps

  1. Create a token

    Pick read & write if the bot should move tickets or post updates.

  2. Add an MCP connector in Grok

    Paste the server URL and the auth header with your token, then save the connector.

  3. Ask your bot “list my Bridge boards”

    It should answer with Example project, Garden planner and Client site redesign.

What your bot can do

read Read only

  • List your boards and projects
  • Read tickets, columns and comments
  • Read project statuses and notes

readwrite Read & write

  • Everything in read only, plus:
  • Move tickets between columns
  • Create tickets and add comments
  • Post status updates on your projects

Bots never see other people's projects, and can't change your password, tokens or account.
